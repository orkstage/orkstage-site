## The repositories

OrkStage is split into focused repositories in the [`orkstage`](https://github.com/orkstage)
organization. The split kept the git history of every part. Shared code is published as
**versioned packages**, and git submodules appear only in the `orkstage-dev` workspace.

| Repository | Contents | Publishes | License |
|---|---|---|---|
| `orkstage` | Control API, worker, shared packages, platform image, docs | `@orkstage/contracts`, `/authorization`, `/templates` and `/domain`; `ghcr.io/orkstage/platform` | AGPL-3.0 |
| `orkstage-ee` (private) | Enterprise source, a git submodule of `orkstage` at `apps/api/src/ee` that clones skip | Built into the official platform image | OrkStage Enterprise License |
| `orkstage-console` | The web console | `ghcr.io/orkstage/console` | AGPL-3.0 |
| `orkstage-cli` | `ork` and the scan engine | Signed `ork` binaries, `@orkstage/scan` (WASM), manifests for Homebrew, Scoop and winget | AGPL-3.0 |
| `orkstage-modules` | OpenTofu modules and the runner image | Git tags `vX.Y.Z`, `ghcr.io/orkstage/tofu-runner:<tag>` | Apache-2.0 |
| `orkstage-site` | This site | Static site on S3 and CloudFront (orkstage.io) | MIT for code, CC BY 4.0 for content |
| `orkstage-dev` | Workspace: submodules, Compose stack, scripts | Nothing | MIT |
| `.github` | Organization profile and default community files | Nothing | |
| `orkstage-licensing` | License signing service (private) | Nothing public | Proprietary |

The packages and images are not published yet. Until they are, the `orkstage-dev` workspace builds
everything from the submodules.

How the repositories depend on each other:

```text
orkstage-console ──npm──▶ @orkstage/contracts, /authorization, /templates, /domain
orkstage (api)   ──npm──▶ @orkstage/scan (from orkstage-cli)
orkstage (worker)──image─▶ ghcr.io/orkstage/tofu-runner:<modules tag>
orkstage-cli     ──HTTP──▶ OrkStage API (integration contract, OpenAPI)
orkstage-site    ──file──▶ OpenAPI JSON published by orkstage CI
orkstage-dev     ──git submodules──▶ every repository (pinned commits)
```

Start with the [development setup](/docs/contributing/development-setup/):

```bash
git clone --recurse-submodules git@github.com:orkstage/orkstage-dev.git
cd orkstage-dev
pnpm bootstrap
```
