What's new

The latest changes to the OrkStage platform, console, CLI and OpenTofu modules, from the changelog that each repository keeps for every release.

Each OrkStage repository keeps a CHANGELOG.md, written from the titles of the pull requests merged into it: features, fixes, performance and documentation. This page shows the latest sections of each one; changes merged since the last release are under Unreleased. See the release process.
